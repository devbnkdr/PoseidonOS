# Contributing

Bug reports, ideas and pull requests are welcome.

- **Bugs:** open an issue and attach the `diag.txt` that `poseidonos/diagnose.sh` writes. Check it
  first and remove anything you'd rather not share.
- **Pull requests:** keep each one focused on a single change, and say what you tested it on
  (Plasma version, X11 or Wayland).
